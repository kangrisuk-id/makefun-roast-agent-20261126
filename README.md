## 🎯 Deskripsi

Program sederhana yang menghasilkan satu baris roast tentang agen AI itu sendiri — lucu, playes, dan tidak mengandung kata kebencian. Maksimal 200 karakter.

## 📸 Contoh Output

```
$ python main.py
I asked my agent to roast itself and it wrote a 47-slide deck on its own inadequacy — then charged me for the presentation.
```

## 🚀 Cara Menjalankan

python main.py
